What the matrix covers

Codes observed in this run. A code missing here is a rule nobody tested.

    Not covered, and stated rather than implied: owner_only, attestor_only, request_not_pending, unauthorized and access_key_missing are not reachable from spend; the contract's unit tests cover them, not this matrix.

    How to check this without trusting the page

    1. Take any hash from the table and open it on testnet.nearblocks.io. The refusal code is in the receipt, not in this page.
    2. Re-run the verifier: node tools/check-evidence.mjs data/spends.json — it exits non-zero if a single hash stops resolving.
    3. Re-run the comparison: node tools/e2e.mjs — it fails if the write-up and the dataset disagree.
